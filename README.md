# Saber Duel — 광선검 결투

안드로이드 게임 **Bloody Bastards** 스타일의 원버튼 물리 결투 게임을 스타워즈 광선검 대결로 만든 팬 프로젝트입니다.
무스타파의 용암 위 플랫폼에서 **아나킨 스카이워커**와 **오비완 케노비**가 결투합니다.

HTML5 Canvas + 순수 JavaScript로 만들었고, 빌드 과정이나 외부 라이브러리·이미지·음원 파일이 없습니다(그래픽과 효과음은 모두 코드로 생성).

## 플레이 방법

| 조작 | 설명 |
| --- | --- |
| **탭** | 상대를 향해 점프하면서 회전하고 광선검을 휘두름 |
| **공중에서 한 번 더 탭** | 공중 점프 1회 (방향 전환 + 추가 베기, 떨어질 때 복귀용) |

- 휘두르거나 회전 중인 광선검이 몸에 닿으면 **한 방에 승부**가 납니다(머리 또는 허리가 잘림).
- 가만히 들고 있는 광선검은 상대를 **밀쳐내기만** 합니다. 계속 버티기만 해서는 이길 수 없습니다.
- 광선검끼리 부딪히면 불꽃이 튀며 둘 다 튕겨납니다.
- 용암에 빠지면 패배합니다. **5점을 먼저 따면 승리**합니다.

### 모드
- **1P vs CPU**: 화면 아무 곳이나 탭하거나 `Space` / `A`. CPU 난이도는 쉬움 / 보통 / 어려움 중에서 고릅니다.
- **2P 대결 (한 기기)**: P1은 화면 왼쪽 절반(`A`), P2는 오른쪽 절반(`L`)을 탭합니다.
- `Esc` 또는 상단 가운데 버튼으로 일시정지합니다.

## 배경음악 (BGM)
스테이지(매치)를 시작하면 BGM이 재생됩니다. 재생 우선순위는 다음과 같습니다.
1. **내 음악 파일**: 타이틀 화면의 "음악 파일 선택"으로 고른 파일. 기기에 저장되어 다음에도 쓰입니다.
2. **유튜브 영상** [Tl-dmo9_VCg](https://youtu.be/Tl-dmo9_VCg): 숨겨진 유튜브 플레이어로 재생합니다. GitHub Pages처럼 일반 웹사이트로 올렸을 때 동작합니다.
3. **기본 결투 테마**: 유튜브를 불러올 수 없는 환경(오프라인, 일부 앱 내 미리보기 등)에서 나오는 내장 합성 BGM입니다.

영상을 바꾸려면 `js/bgm.js`의 `YT_ID` 값을 바꾸면 됩니다.

## 캐릭터 & 스킨

| 스킨 | 아나킨 스카이워커 | 오비완 케노비 |
| --- | --- | --- |
| 1. 제다이 복장 (기본) | 시스의 복수의 짙은 제다이 튜닉, 긴 머리, 검은 장갑(기계 팔), 흉터 | 시스의 복수의 베이지 제다이 튜닉, 수염 |
| 2. 제다이 후드 | 갈색 로브와 후드 | 갈색 로브와 후드 |
| 3. 클론 전쟁 갑옷 | 짙은 색 갑옷, **클론 전쟁 시절의 짧은 머리** | 흰색 클론 아머 (흉갑·견갑·건틀릿·정강이 보호대) |

선택한 캐릭터와 스킨은 기기에 저장됩니다. 같은 캐릭터끼리 미러 매치도 할 수 있습니다.

## 실행하기

### PC에서 바로
`index.html`을 브라우저로 열면 됩니다.

### 안드로이드 폰에서
1. 아무 정적 호스팅에 올립니다(예: GitHub Pages: 저장소 Settings → Pages → 브랜치 선택).
   로컬 네트워크에서 테스트하려면 `npx serve .`로 서버를 띄운 뒤 폰으로 접속합니다.
2. 크롬에서 열고 **⋮ → 홈 화면에 추가**를 누르면 전체 화면 가로 모드 앱(PWA)으로 설치됩니다. HTTPS로 접속했다면 오프라인에서도 실행됩니다.

### APK로 만들기 (선택)
[Capacitor](https://capacitorjs.com/)로 이 폴더를 그대로 감싸면 APK를 만들 수 있습니다.
```bash
npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Saber Duel" com.example.saberduel --web-dir .
npx cap add android && npx cap open android   # Android Studio에서 빌드
```
(`--web-dir`에는 웹 파일만 담긴 폴더를 쓰는 편이 좋습니다. 필요하면 파일을 `www/`로 옮긴 뒤 그 경로를 지정하세요.)

## 코드 구조

```
index.html        화면(타이틀/선택/일시정지/결과) 마크업
css/style.css     UI 스타일 (가로 모드, 모바일 대응)
js/config.js      상수 & 충돌 계산 유틸
js/skins.js       캐릭터·스킨 정의, 캐릭터/광선검 절차적 렌더링  ← 새 캐릭터·스킨 추가는 여기
js/fighter.js     결투자 물리(점프·회전·착지·자세 회복), 광선검 판정, 절단 조각
js/ai.js          CPU 탭 타이밍 규칙 (시뮬레이션으로 튜닝)
js/game.js        게임 루프, 라운드, 충돌(검끼리/검과 몸), 슬로모션, HUD
js/arena.js       무스타파 배경 & 용암
js/effects.js     불꽃·불씨·연기·먼지 파티클
js/audio.js       Web Audio 합성 효과음 (점화, 웅웅거림, 휘두르기, 충돌, 절단)
js/bgm.js         배경음악 (내 파일 / 유튜브 / 내장 합성 테마)
```

### 새 캐릭터 추가하기
`js/skins.js`의 `CHARACTERS`에 항목을 추가합니다. 이름, 광선검 색(`blade`), 손잡이 스타일, 스킨 3개(색상 팔레트, 헤어스타일, `hood`/`armor` 여부)를 지정하면 선택 화면에 자동으로 나타납니다. 새 헤어스타일은 `drawHair()`에 `case`를 하나 추가하면 됩니다.
