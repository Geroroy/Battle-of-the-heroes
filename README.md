# Saber Duel — 광선검 결투

안드로이드 게임 **Bloody Bastards** 스타일의 원버튼 물리 결투 게임을 스타워즈 광선검 대결로 만든 팬 프로젝트입니다.
무스타파의 용암 위 플랫폼에서 **아나킨 스카이워커**와 **오비완 케노비**가 결투합니다.

HTML5 Canvas + 순수 JavaScript로 만들었고, 빌드 과정이나 외부 라이브러리·이미지·음원 파일이 없습니다.
그래픽은 Bloody Bastards 의 아트 스타일에 스타워즈 무스타파를 섞은 **픽셀 아트**입니다. 게임 화면은 480×270 저해상도로 그린 뒤 선명하게 확대하고, 배경(화산, 채굴 시설, 관전하는 배틀 드로이드, 떨어지는 화산재)은 제한 팔레트로 디더링했습니다.
글꼴은 한글 픽셀 글꼴 [갈무리(Galmuri)](https://github.com/quiple/galmuri)를 씁니다 (SIL OFL 1.1, `fonts/OFL-Galmuri.md`).

## 플레이 방법

**Bloody Bastards** 처럼 화면 양쪽의 가상 조이스틱으로 래그돌 몸과 광선검 팔을 직접 움직입니다.

| 모드 | 왼쪽 스틱 | 오른쪽 스틱 |
| --- | --- | --- |
| **1P vs CPU** | 이동 (좌우 걷기, 위로 밀면 점프, 아래로 웅크리기) · 키보드 `WASD` | 광선검 팔 조준 · 키보드 방향키 / 마우스 드래그 |
| **2P 한 기기** | P1 광선검 (`WASD`) | P2 광선검 (방향키) |

- 스틱은 엄지를 댄 자리가 중심이 되는 플로팅 방식이고, 두 엄지를 동시에 쓸 수 있습니다. 2P에서는 몸이 자동으로 상대와 거리를 맞춥니다.
- 광선검은 **빠르게 휘둘러야** 벱니다. 칼날이 지나간 팔·손·다리·발·목·몸통이 각각 잘려 나가고 절단면이 지져집니다.
- 몸통은 첫 타격에 상처만 나고, 두 번째에 두 동강 납니다.
- 칼끼리 부딪히면 불꽃이 튀며 막힙니다. 막는 순간에는 베이지 않습니다.
- **목이나 몸통이 잘리거나, 양팔을 모두 잃거나, 용암에 빠지면** 그 라운드에서 집니다. 다리를 잃으면 절뚝이거나 주저앉은 채로 싸웁니다.
- 3점을 먼저 따면 승리합니다. CPU 난이도(쉬움/보통/어려움)는 휘두르는 속도, 반응, 막기 확률이 다릅니다.
- `Esc` 또는 상단 가운데 버튼으로 일시정지합니다.

## 배경음악 (BGM)
스테이지(매치)를 시작하면 BGM이 재생됩니다. 재생 우선순위는 다음과 같습니다.
1. **내 음악 파일**: 타이틀 화면의 "음악 파일 선택"으로 고른 파일. 기기에 저장되어 다음에도 쓰입니다.
2. **유튜브 영상** [Tl-dmo9_VCg](https://youtu.be/Tl-dmo9_VCg): 숨겨진 유튜브 플레이어로 재생합니다. GitHub Pages처럼 일반 웹사이트로 올렸을 때 동작합니다.
3. **기본 결투 테마**: 유튜브를 불러올 수 없는 환경(오프라인, 일부 앱 내 미리보기 등)에서 나오는 내장 합성 BGM입니다.

영상을 바꾸려면 `js/bgm.js`의 `YT_ID` 값을 바꾸면 됩니다.

## 캐릭터 & 스킨

| 스킨 | 아나킨 스카이워커 | 오비완 케노비 |
| --- | --- | --- |
| 1. 클론 전쟁 (기본) | 건메탈 흉갑과 붉은 제다이 문장 견갑, 남색 무릎길이 타바드, 버건디 튜닉·바지, 긴 갈색 가죽 건틀릿, 스트랩 달린 갈색 부츠, 웨이브 진 머리, 흉터 | 흰 클론 아머(흉갑·복부·팔·정강이)와 붉은 문장 견갑, 크림색 타바드, 검은 언더슈트와 장갑, 회색 부츠 |
| 2. 제다이 복장 | 시스의 복수의 짙은 튜닉, 검은 장갑 | 시스의 복수의 베이지 튜닉 |
| 3. 제다이 후드 | 로브와 후드 | 로브와 후드 |

캐릭터는 Bloody Bastards 처럼 정면에 가까운 3/4 얼굴의 디테일한 픽셀 아트입니다. 머리·몸통·위팔·아래팔·허벅지·정강이를 각각 따로 그린 스프라이트라서 래그돌 뼈를 따라 회전하고, 잘리면 그 부위만 떨어져 나갑니다.

## 실행하기

### PC에서 바로
`index.html`을 브라우저로 열면 됩니다.

### 안드로이드 폰에서
1. 아무 정적 호스팅에 올립니다(예: GitHub Pages: 저장소 Settings → Pages → 브랜치 선택).
   로컬 네트워크에서 테스트하려면 `npx serve .`로 서버를 띄운 뒤 폰으로 접속합니다.
2. 크롬에서 열고 **⋮ → 홈 화면에 추가**를 누르면 전체 화면 가로 모드 앱(PWA)으로 설치됩니다. HTTPS로 접속했다면 오프라인에서도 실행됩니다.

### APK로 만들기 (선택)
[Capacitor](https://capacitorjs.com/)로 이 폴더를 그대로 감싸면 APK를 만들 수 있습니다.
```bash
npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Saber Duel" com.example.saberduel --web-dir .
npx cap add android && npx cap open android   # Android Studio에서 빌드
```
(`--web-dir`에는 웹 파일만 담긴 폴더를 쓰는 편이 좋습니다. 필요하면 파일을 `www/`로 옮긴 뒤 그 경로를 지정하세요.)

## 코드 구조

```
index.html        화면(타이틀/선택/일시정지/결과) 마크업
css/style.css     UI 스타일 (가로 모드, 모바일 대응)
js/config.js      상수 & 충돌 계산 유틸
js/skins.js       캐릭터·스킨 정의, 부위별 픽셀 스프라이트(머리 격자 + 절차적 몸통·팔다리), 광선검 픽셀 렌더링  ← 새 캐릭터·스킨 추가는 여기
js/fighter.js     액티브 래그돌 (Verlet 입자·뼈 제약·근육), 걷기·점프, 양손 광선검, 부위 절단
js/input.js       양쪽 가상 조이스틱(멀티터치) + 키보드·마우스
js/ai.js          CPU: 거리 유지, 들어올려 베기, 막기 (난이도별 휘두르기 속도)
js/game.js        게임 루프, 라운드, 칼끼리 충돌·절단 판정, 슬로모션, HUD
js/arena.js       무스타파 배경 & 용암
js/effects.js     불꽃·불씨·연기·먼지 파티클
js/audio.js       Web Audio 합성 효과음 (점화, 웅웅거림, 휘두르기, 충돌, 절단)
js/bgm.js         배경음악 (내 파일 / 유튜브 / 내장 합성 테마)
```

### 새 캐릭터 추가하기
`js/skins.js`의 `CHARACTERS`에 항목을 추가합니다. 스킨마다 팔레트(글자 → 색), 머리(`HEADS`의 격자 이름), 몸통·팔·다리 스타일을 지정하면 선택 화면에 자동으로 나타납니다. 머리 격자에서 글자 하나가 한 픽셀이고 `k`는 외곽선, `.`은 투명입니다. 몸통과 팔다리는 그리는 함수가 팔레트로 칠한 뒤 외곽선을 자동으로 두릅니다.
